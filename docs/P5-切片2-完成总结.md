# P5 切片 2 完成总结

## 任务目标

实现四季夏目 P5 第二切片：本地主动搭话 + 勿扰模式。

## ✅ 已完成

### 1. 主动搭话机制

#### 1.1 策略实现（`src/core/policy/local.py`）
- `ALLOW_PROACTIVE = True` 启用本地主动
- `should_allow_proactive()` 判断函数
- `generate_proactive_prompt()` 随机生成开场白：
  - 「很久没听到你的声音了。」
  - 「在忙吗？」
  - 「还在吗？」
  - 「突然有点想你。」
  - 「…嗯，该说点什么呢。」
  - 「无聊。」

#### 1.2 活动时间跟踪（`src/core/session.py`）
- `_last_activity: dict[str, float]` 记录每个会话的最后活动时间
- `last_activity_time(chat_id)` 方法查询活动时间
- `append()` 方法自动更新活动时间戳

#### 1.3 FastAPI 端点（`src/main.py`）
- **GET `/api/proactive/status`**
  - 查询主动搭话配置和状态
  - 返回：enabled、do_not_disturb、idle_timeout_s、cooldown_s、last_activity_ms

- **POST `/api/proactive/trigger`**
  - 触发主动搭话（由桌宠定时器调用）
  - 检查勿扰、空闲时间、冷却时间
  - 生成 InboundMessage 送给 Agent
  - 返回消息文本、emotion、TTS 音频 URL

- **POST `/api/proactive/dnd`**
  - 切换勿扰模式
  - 参数：`{ "enabled": true/false }`
  - 运行时状态，不持久化到 config.yaml

### 2. Electron 桌宠增强

#### 2.1 定时器（`desktop/main.js`）
- 每 60 秒调用 `/api/proactive/trigger`
- 尊重勿扰模式和冷却时间
- 窗口关闭时自动清理定时器

#### 2.2 系统托盘（`desktop/main.js`）
- 创建托盘图标（16x16 Base64 编码）
- 右键菜单：
  - 显示窗口
  - 勾选「勿扰模式」
  - 退出
- 托盘图标点击显示窗口

#### 2.3 勿扰模式同步
- 状态保存在 electron-store
- 切换时通知 FastAPI（POST `/api/proactive/dnd`）
- 菜单显示实时勾选状态

#### 2.4 IPC 通信（`desktop/preload.js`）
- `getDndStatus()` 查询勿扰状态
- `toggleDnd()` 切换勿扰模式
- `onProactiveMessage(callback)` 接收主动消息

### 3. 配置系统（`config.yaml`）

```yaml
proactive:
  enabled: true              # 是否启用主动搭话
  idle_timeout_s: 300        # 冷场多久后主动（5 分钟）
  random_talk_prob: 0.1      # 随机碎碎念概率（暂未实现）
  cooldown_s: 600            # 主动搭话最小间隔（10 分钟）
  do_not_disturb: false      # 初始勿扰状态
```

## 🚀 如何使用

### 启动

1. **FastAPI 后端**：
   ```bash
   python -m src.main
   ```

2. **桌宠窗口**：
   ```bash
   cd desktop
   npm install  # 首次运行（新增 node-fetch 依赖）
   npm start
   ```

### 测试主动搭话

1. 启动 FastAPI 和桌宠
2. 与她聊天一次（建立活动时间）
3. 等待 5 分钟不互动
4. 她会主动说话

### 切换勿扰模式

1. 右键任务栏托盘图标（系统托盘）
2. 勾选「勿扰模式」暂停主动
3. 再次点击取消勾选恢复

### 调整配置

编辑 `config.yaml`：
- `idle_timeout_s`: 冷场时间（秒）
- `cooldown_s`: 冷却时间（秒）
- `do_not_disturb`: 初始勿扰状态

## 📝 技术实现

### 主动搭话流程

```
Electron 定时器（60s）
       ↓
POST /api/proactive/trigger
       ↓
FastAPI 检查
  - 勿扰模式？
  - 空闲时间 >= idle_timeout_s？
  - 距上次主动 >= cooldown_s？
       ↓
生成 InboundMessage
       ↓
Agent（人设 + 上下文）
       ↓
返回 OutboundMessage
  - texts（中文）
  - emotion
  - speech_ja
       ↓
TTS 合成音频
       ↓
返回 JSON
  - triggered: true
  - texts
  - emotion
  - audio_url
       ↓
Electron 接收并播放
```

### 勿扰模式同步

```
用户点击托盘菜单
       ↓
toggleDoNotDisturb()
       ↓
electron-store 保存状态
       ↓
POST /api/proactive/dnd { enabled: true }
       ↓
FastAPI 更新运行时状态
       ↓
托盘菜单显示勾选
```
