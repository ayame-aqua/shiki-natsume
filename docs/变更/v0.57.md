## 变更内容

### 新增

- **Live2D 集成**：聊天页左侧显示 Live2D 形象（借鉴 AIRI / pixi-live2d-display）
  - `web/live2d.js`：Live2D 驱动逻辑
  - `web/live2d/model_dict.json`：模型配置文件（空，需用户自行配置）
  - `web/live2d/README.md`：模型放置说明
- **表情切换**：根据 Agent 输出的 emotion（neutral/happy/sad/angry/shy）自动切换表情
  - 表情映射 `EMOTION_MAP` 支持自定义 emotionMap
  - 缺失表情时回退到 neutral 并在控制台警告
  - 表情保持 2 秒后自动回到 neutral
- **RMS 口型同步**：TTS 播放时根据音频振幅驱动 ParamMouthOpenY
  - 使用 AudioContext + AnalyserNode 实时分析音频
  - 平滑系数 0.35，避免抖动
  - 音频结束后自动关闭嘴巴
- **Idle 动画**：
  - 眨眼：每 4 秒触发一次 ParamEyeLOpen/ParamEyeROpen
  - 呼吸：每 3 秒平滑变化 ParamBreath
- **优雅降级**：
  - 未配置模型时显示"未配置模型"占位符
  - 模型加载失败时显示"模型加载失败"
  - 聊天和语音功能不受影响

### 布局

- 左侧：Live2D 容器（400px 宽）
- 右侧：聊天区域（原有布局）
- 窄屏（< 900px）：Live2D 移至底部（200px 高），聊天优先
- 超窄屏（< 600px）：Live2D 高度减至 150px

### 技术实现

- 前端库：pixi.js@7.4.2 + pixi-live2d-display@1.2.0（CDN）
- 后端：FastAPI 静态文件服务 `/live2d`
- 无桌宠窗口、系统托盘、全局置顶

## 使用说明

### 配置 Live2D 模型

1. 将有权使用的 Cubism 3–5 模型放到 `web/live2d/natsume/`
2. 编辑 `web/live2d/model_dict.json`：

```json
[
  {
    "name": "natsume",
    "url": "/live2d/natsume/model.model3.json",
    "kScale": 0.4,
    "emotionMap": {
      "neutral": "idle",
      "happy": "smile",
      "sad": "sad",
      "angry": "angry",
      "shy": "blush"
    }
  }
]
```

3. 刷新页面，模型应出现在左侧
