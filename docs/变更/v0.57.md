## 做什么

把 P4 合进 `main` 之后，按审查把口型和播放接回同一条链路。聊天页左侧可以挂 Cubism 3–5 皮；没配模型时只显示「未配置模型」，文字和语音不受影响。

TTS 仍走 `v0.49` 已解锁的 `AudioContext`。口型吃这条图上的 `AnalyserNode`，不再 `new Audio()`，也不再 `createMediaElementSource`。

## 为什么

PR #1 的骨架能用，但为了接口型把 TTS 退回 `<audio>.play()`，第一句会再被浏览器拦掉。它引用的 `pixi-live2d-display@1.2.0` 在 npm 上不存在，也没加载 Cubism Core。表情 2 秒就打回 idle，眨眼/呼吸用 `setInterval` 写一次参数，下一帧会被 motion 盖掉。

## 改了什么

- `web/app.js`：恢复 `decodeAudioData` + `BufferSource` 播放；`AnalyserNode` 交给 Live2D；`emotion` 只在 `assistant_text` 设一次，播完再 `releaseEmotion`
- `web/live2d.js`：口型、眨眼、呼吸挂在模型 `update` 之后；表情先 `expression()` 再 motion；占位不再拆掉 canvas；IIFE 包起来，避免和 `app.js` 的 `analyser` 撞名导致聊天脚本不执行
- `web/index.html`：Cubism Core 官方 CDN + `pixi-live2d-display@0.5.0-beta` 的 `cubism4`
- `web/style.css`：聊天区在视口内滚动，不再 `body { overflow: hidden }` 加 `min-height: 100vh`
- `src/main.py`：`/live2d` 静态托管（随 PR 合入）
- `.gitignore`：模型 json / 本机 Cubism Core 不入库
- P4 方案与总纲：只勾占位和降级；口型、四态、idle 待本机挂皮
