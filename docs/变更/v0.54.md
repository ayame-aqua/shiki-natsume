## 做什么

采集图不再把麦克风回灌到扬声器。AudioContext 跟麦的采样率对齐。关掉 `echoCancellation`。

v0.51 为了让 Chrome 的 Analyser 出数，把麦接到了 `gain=0` 的 destination。再叠加回声消除，浏览器把输入当成回声整段抵消。日志里是：

```
band=0.000 floor=0.008 rec=1 voice=0
```

录音在转，分析器是静音，VAD 每 2.5 秒把片段当空白丢掉，所以「识别不到」而且音量一直是 0。这不是 SenseVoice 的问题。

## 为什么

音量是 0 时，后面换什么 ASR 都听不见。

## 改了什么

- `web/app.js`：分析器接到 `MediaStreamDestination`，不进扬声器；`AudioContext({ sampleRate })` 对齐麦；关掉 AEC / NS；音量条带设备名；连续 4 秒为 0 提示换设备
