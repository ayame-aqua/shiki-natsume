## 做什么

本机验收时 GPT-SoVITS 没在 `9880` 听，每回一句就要连三次权重/合成接口，`main.py` 用 `logger.exception` 把整段 `ConnectTimeout` 栈打红。改成传输失败只记一行警告，并冷却 30 秒不再连。

## 为什么

文字聊天本来就可以在没有 TTS 时继续。刷栈会让人以为 `src/main.py` 崩了。

## 改了什么

- `src/speech/tts.py`：`TransportError` 标记不可达；设权重连不上就停，不再继续 POST `/tts`
- `src/speech/constants.py`：`TTS_UNREACHABLE_COOLDOWN_S = 30`
- `src/main.py`：合成失败改 `warning`，不再 `exception`
- `tests/test_tts.py`：超时后第二次调用不再打 HTTP
