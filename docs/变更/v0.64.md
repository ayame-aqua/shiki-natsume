## 做什么

桌宠主动开口时能带上「你现在大概在干什么」：读前台窗口标题/进程，粗分成写代码、打游戏、看视频、浏览等，写进 system Inbound。切到新应用且短空闲后，也可以因焦点变化触发。

## 为什么

P5 验收要「切到明显不同的应用，她有可能提到你在干什么」。截屏多模态是 S4；标题这一截先通，且不依赖无许可的第三方桌宠仓。

## 改了什么

- `src/vision/`：`classify_scene` + Win32 `read_foreground`；自窗只认标题「四季夏目」/本进程，避免误伤仓库名或视频标题
- `src/core/proactive.py`：焦点变化门闩 + 同窗冷却
- `src/core/policy/local.py`：主动指令可附带窗口线索，禁止编造屏幕细节
- `src/main.py`：`/api/vision/foreground`；`/api/proactive/trigger` 带 reason / foreground
- `config.yaml`：`vision` 段（`use_screenshot: false`）
- `tests/test_foreground.py`
