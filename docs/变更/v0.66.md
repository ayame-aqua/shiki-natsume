## 做什么

主动搭话时可截主屏缩成 ≤768px JPEG，让多模态模型写一句描述，连同窗口标题塞进 system Inbound。黑名单窗不截；托盘 / `Ctrl+Shift+F9` 可暂停看屏；`see_screen` 仅本机，QQ 通道直接拒绝。截屏默认不落盘、不进记忆。

## 为什么

P5 验收要「切应用可能提到你在干什么」和「黑名单不截屏 / 热键暂停 / 屏幕细节不进 profile」。标题不够时需要截屏；必须和桌宠策略绑在一起，不能给 QQ。
