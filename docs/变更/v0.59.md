## 本版做了什么

P5 桌宠陪伴第一切片：**最小化 Electron 透明桌宠窗口**，复用现有 web UI。

### 新增

1. **Electron 桌宠窗口**（`desktop/` 目录）
   - 无边框、透明、始终置顶
   - 可拖拽（点击 Live2D 区域或标题栏）
   - 自动加载 `http://127.0.0.1:8787`（现有 FastAPI web UI）
   - 持久化窗口位置（使用 electron-store）
   - 独立 DevTools 窗口便于调试

2. **桌宠专用样式**（`web/desktop.css`）
   - `-webkit-app-region: drag` 支持窗口拖拽
   - 保持按钮、文本框等交互元素可点击
   - 透明背景支持

3. **文档**
   - `desktop/README.md`：桌宠窗口使用说明
   - 主 README 更新提及桌宠窗口

### 技术细节

- Node 依赖：`electron@^28.0.0`、`electron-store@^8.1.0`
- Windows 优先（透明窗口 API 已测试）
- 窗口配置保存在系统用户配置目录

### 改动文件

- `desktop/package.json` — Electron 项目配置
- `desktop/main.js` — 主进程：窗口创建、透明、置顶、位置持久化
- `desktop/preload.js` — 预加载脚本：安全 IPC 桥接
- `desktop/README.md` — 桌宠窗口使用文档
- `desktop/.gitignore` — 排除 node_modules、dist
- `web/desktop.css` — 桌宠拖拽样式
- `.gitignore` — 排除 desktop 构建产物
- `docs/变更/v0.59.md` — 本文档

## 运行方式

### 1. 启动 FastAPI（必须先启动）

```bash
cd /workspace
python -m src.main
```

确认 http://127.0.0.1:8787 可访问。

### 2. 启动桌宠窗口

```bash
cd desktop
npm install  # 首次运行
npm start
```
