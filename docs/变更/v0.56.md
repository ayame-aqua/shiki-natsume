## 做什么

给四季夏目加 DeepSeek Harness，但只当 QQ 的手脚：官方 `dsh-qqbot` 负责扫码绑定和消息收发，可见台词仍由本仓库 Agent 生成。人设、记忆、`[[natsume]]`、SoVITS 不搬进 DSH。

登录器仍等 P5。本版只改计划，不写扫码代码。

## 为什么

网上用 dsh 养 DeepSeek、接 QQ 的案例可以借通道，不能把仓库改成又一个 dsh 陪伴插件。只把 `characters/natsume.md` 贴进 DSH，她会变成带着 bash 工具的通用助手，网页和 QQ 也会变成两份记忆。
