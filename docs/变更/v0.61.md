## 做什么

加一个本机启动脚本，双击就能起官方 `dsh web`，不必每次手打命令。

## 为什么

DSH 是旁路运行时，工作目录必须是用户主目录，不能把本仓库当成它的 workspace。命令本身很短，但 PATH、端口占用、Node 版本每次都要核对。

## 改了什么

- `scripts/start_dsh.ps1`：检查 Node 24.9+ 和全局 `dsh`；3080 已在听就打开页面；否则从 `%USERPROFILE%` 起 `dsh web`
- `scripts/start_dsh.bat`：双击入口，绕过 PowerShell 执行策略
- 三份 README 快速开始、总纲目录树、`docs/开发计划/P6-QQ通道/方案.md`
