## 做什么

按 [AudioTTS可行性.md](../开发计划/P3-语音听和说/AudioTTS可行性.md)：识别换引擎、合成仍 SoVITS。默认 ASR 从 Fun-ASR-Nano 换成 **SenseVoice-Small**。

Nano 是小 LLM 解码，短、吵、被切碎的片段容易编词，而且 `forced_align` 缺 `torchaudio` 时每句都先崩再静默退 Whisper。SenseVoice 非自回归一遍出字，同一套 FunASR + `fsmn-vad`，不吃 `trust_remote_code`。

`transcribe()` / `synthesize()` 边界不动。GPT-SoVITS、口型 wav、Agent 都不改。

## 为什么

听不准。方案写明不要把 AudioTTS / CosyVoice 接到识别口上；下一步是开已经写好的 SenseVoice，不是换出声引擎。

## 改了什么

- `src/speech/asr.py`：`FunasrSpec` 区分 SenseVoice / Nano；默认 SenseVoice；`generate` 带 `language=zh`、`use_itn`、`merge_vad`、`ban_emo_unk`；主力失败后粘住回退 Whisper
- `src/speech/constants.py` / `config.yaml`：`asr_model: sensevoice-small`
- `scripts/check_asr.py`：`--model` 可并排核对
- `tests/test_asr.py`：默认规格、Nano 仍可选、回退粘住
- P3 方案 / 本地资源 / 借鉴：默认改为 SenseVoice
