## 本版做了什么

P5 桌宠陪伴第二切片：**本地主动搭话 + 勿扰模式**。

### 新增

1. **主动搭话机制**（`src/core/policy/local.py`）
   - `ALLOW_PROACTIVE = True` 启用本地主动
   - `generate_proactive_prompt()` 生成主动消息提示
   - 支持随机选择不同的开场白

2. **FastAPI 端点**（`src/main.py`）
   - `GET /api/proactive/status`：查询主动搭话状态和配置
   - `POST /api/proactive/trigger`：触发主动搭话（供桌宠定时器调用）
   - `POST /api/proactive/dnd`：切换勿扰模式

3. **活动时间跟踪**（`src/core/session.py`）
   - `last_activity_time(chat_id)` 方法
   - 自动记录每次对话的活动时间戳

4. **桌宠定时器**（`desktop/main.js`）
   - 每 60 秒检查一次是否需要主动搭话
   - 尊重勿扰模式和冷却时间
   - 定时器在窗口关闭时自动清理

5. **系统托盘**（`desktop/main.js`）
   - 托盘图标和右键菜单
   - 勾选「勿扰模式」暂停主动搭话
   - 快速显示窗口和退出应用

6. **配置选项**（`config.yaml`）
   ```yaml
   proactive:
     enabled: true              # 是否启用主动搭话
     idle_timeout_s: 300        # 冷场多久后主动（5 分钟）
     random_talk_prob: 0.1      # 随机碎碎念概率
     cooldown_s: 600            # 主动搭话最小间隔（10 分钟）
     do_not_disturb: false      # 初始勿扰状态
   ```

### 技术细节

#### 主动搭话流程
1. Electron 定时器每 60 秒调用 `/api/proactive/trigger`
2. FastAPI 检查：
   - 勿扰模式是否开启
   - 距离上次活动是否 >= `idle_timeout_s`
   - 距离上次主动是否 >= `cooldown_s`
3. 条件满足时：
   - 生成主动提示文本
   - 创建 `InboundMessage` 送给 Agent
   - Agent 根据人设和上下文生成回复
   - 返回消息、emotion、TTS 音频
4. Electron 接收后渲染进程显示和播放

#### 勿扰模式
- 状态保存在 `electron-store`（`%APPDATA%\shiki-natsume-desktop\config.json`）
- 托盘菜单切换时同步到 FastAPI
- FastAPI 运行时内存状态，不持久化到 `config.yaml`

#### 冷却机制
- `app.state.last_proactive_time` 记录上次主动时间
- 防止频繁打扰

## 运行方式

### 1. 启动 FastAPI（必须先启动）

```bash
python -m src.main
```

### 2. 启动桌宠窗口

```bash
cd desktop
npm install  # 首次运行（新增 node-fetch 依赖）
npm start
```

### 3. 使用勿扰模式

- 右键托盘图标（任务栏右下角）
- 勾选「勿扰模式」暂停主动搭话
- 再次点击取消勾选恢复主动搭话

## 为什么

按总纲和 P5 方案：
- 主动搭话是桌宠核心体验（「经常被她搭话」）
- 勿扰模式必须简单快捷（热键或托盘菜单）
- 冷却机制避免「开着两小时完全不说话」的反例
- 复用现有 Agent/TTS/Live2D，不重复实现
- 先做无 CV 的主动（冷场计时），再做有 CV 的主动（窗口切换）
- 切片 2 不引入复杂的窗口监控和截屏，降低风险
