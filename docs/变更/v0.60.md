## 做什么

#2 的透明桌宠窗已经进 `main`。#3 只打了 HTTP 定时器，网页听不到、也看不见。本版把主动句改成 system Inbound，判定单独拆开，生成后经 ChatHub 广播原来的 `assistant_text` / `assistant_audio` 帧。托盘勿扰改成后端运行时状态，启动时从 Electron 同步过来。

## 为什么

桌宠「过一会儿来找你」必须走同一张嘴：气泡、TTS、口型。不能把「在忙吗？」写成用户发言，也不能只在主进程 `console.log`。

## 改了什么

- `src/core/proactive.py`：冷场 / 冷却 / 勿扰 / 开关判定
- `src/core/policy/local.py`：system 指令，不再伪装用户台词
- `src/core/agent.py`：`chat_type=system` 不写用户轮、不抽记忆
- `src/core/session.py`：记录最后活动时间
- `src/channels/chat_hub.py`：已连接 WebSocket 广播
- `src/main.py`：`/api/proactive/status|trigger|dnd`
- `config.yaml`：`proactive` 段
- `desktop/main.js` / `preload.js` / `package.json`：托盘勿扰、去掉 node-fetch 和打包空壳
- `web/app.js` / `web/desktop.css`：Electron 里才挂拖拽样式，聊天区半透明底
- `tests/test_proactive.py`
- 三份 README、总纲、`desktop/README.md`
