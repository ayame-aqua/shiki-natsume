# P5 桌宠窗口验证指南

本文档用于验证 P5 第一切片的桌宠窗口功能是否正常工作。

## 验证前提

1. ✅ Python 3.11+ 已安装
2. ✅ Node.js 16+ 已安装
3. ✅ Windows 10+ 系统（优先支持）

## 步骤 1：启动 FastAPI 后端

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -e ".[dev]"

# 配置 .env
copy .env.example .env
# 编辑 .env，填入 LLM_API_KEY

# 启动后端
python -m src.main
```

**验证点 1.1**：访问 http://127.0.0.1:8787，能看到网页聊天界面。

## 步骤 2：安装并启动桌宠窗口

新开一个终端：

```bash
cd desktop
npm install
npm start
```

**验证点 2.1**：Electron 窗口成功启动。  
**验证点 2.2**：窗口显示与浏览器访问 127.0.0.1:8787 相同的内容。

## 常见问题

### 窗口启动失败

**症状**：`npm start` 后无窗口出现，或出现错误。  
**检查**：
1. FastAPI 是否在 127.0.0.1:8787 运行？
2. Node.js 版本是否 >= 16？
3. 查看终端错误信息

### 窗口不透明

**症状**：窗口有白色或黑色背景。  
**原因**：部分 Windows 版本或显卡驱动不完全支持透明窗口。  
**解决**：更新显卡驱动；检查 Windows 版本是否支持 DWM 透明。

### 无法拖拽

**症状**：点击任何区域都无法移动窗口。  
**检查**：
1. `web/desktop.css` 是否被正确加载？
2. 打开 DevTools Console 查看是否有 CSS 注入错误

### 窗口位置不保存

**症状**：每次启动窗口都在默认位置。  
**检查**：
1. 配置文件路径是否有写入权限？
2. 查看 `main.js` 中 `store.get('windowBounds')` 日志
